NVIDIA Nemotron 3 Ultra is a 550B total / 55B active parameter Mixture-of-Experts hybrid Mamba-Attention model released June 2026. It achieves ~6x higher inference throughput than comparable open LLMs while matching state-of-the-art accuracy across benchmarks. Supports 1M token context length, optimized for long-horizon autonomous agentic tasks with a multi-stage post-training pipeline (RLVR, RLHF, MOPD).
